A program that draws a newspaper front page summing up 25 November 2026 world news in one 1024x1024 image: the ICJ finds Myanmar guilty of genocide against the Rohingya (9-6, the first state verdict), Ukraine hits a Russian cargo ship in the Gulf of Finland and sea drones sink the corvette Merkury off Benghazi, COP31 collapses in Antalya with no fossil-fuel deal, NATO vows to defend space, Houthis hit Riyadh's tallest tower, Microsoft declares Code Red after a historic outage, China launches Shenzhou-24 with the first Pakistani astronaut, plus GTA 6's 39M PS5 players, the Nepal quake, the Israel airstrike in Gaza, Huawei's trade-secret verdict and South Korea's education minister resigning in brief.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Pure Python standard library, no network. Running it twice writes identical bytes.
